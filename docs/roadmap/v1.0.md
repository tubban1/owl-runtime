# OWL Runtime Roadmap to 1.0

Current development line: **0.10.0-dev.0**.

Target: **1.0.0-rc.1**, then **1.0.0** after dogfood and soak.

The feature surface is now locked. See [1.0 Scope Lock](1.0-scope-lock.md). New product features do not enter 1.0 unless they fix correctness, security, recovery, cancellation, ownership/isolation, public-contract compatibility, or production reliability.

## Already complete

- standalone production Runtime daemon, independent of MCP;
- local RuntimeClient / HTTP public API v0.1;
- stable logical session identity across requests;
- reconnect-safe process control capability;
- request cancellation propagated to shell process groups;
- persistent Tasks, Scheduler, Loop, staging, existing memory contracts;
- workspace ownership / Resource Arbiter / concurrency;
- state schema / migrations / candidate upgrade / rollback;
- Observation ABI;
- Verifier ABI;
- File postcondition verification;
- Browser postcondition baseline;
- Managed Process state machine;
- one-time Approval receipts;
- Execution Health model;
- production install/upgrade/rollback verification;
- recovery and concurrency matrices.
